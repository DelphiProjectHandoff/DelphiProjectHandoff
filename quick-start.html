Build DPH from source.

Five steps from the clean source ZIP to a working Win32 or Win64 build in RAD Studio 37.

This guide is for the build-ready source ZIP, not the ready-to-run Windows downloads. You do not need the Win32 ZIP, Win64 ZIP, or optional translation-authoring ZIP to compile the source. Get the 0.8.0.21 source ZIP.

  1. Extract the entire source ZIP

    Choose a writable local folder. Extract all files and keep the folders together; do not open or build files while they are still inside the ZIP.

  2. Install the language design package

    Before opening the project, start RAD Studio 37 and choose Component → Install Packages → Add. Inside the extracted folder, select export\DAT-component-kit\DelphiProjectHandoff\DesignPackages\Win32\Release\DATLanguageManagerFMXDesign.bpl.

    Leave DATLanguageManagerCoreRuntime.bpl and DATLanguageManagerFMXRuntime.bpl in that same folder. You do not add those two BPLs separately. Confirm the design package is enabled; restart the IDE if prompted. The Win32 design package is correct even when building the Win64 app.

  3. Open the project in the IDE

    In RAD Studio, choose File → Open Project. Browse to the top level of the extracted source folder and select DelphiProjectHandoff.dproj. Do not open DPH.UI.Main.fmx by itself. Its two language controls are already on the form.

  4. Build the Windows edition you need

    In Project Manager, select Win32 or Win64, select Release, then choose Build. The project already includes the translation dependency in its compiler search path; there is no separate dependency-preparation step.

  5. Run your build

    Open bin\Win32\Release\DelphiProjectHandoff.exe or bin\Win64\Release\DelphiProjectHandoff.exe inside the extracted folder. Check that WebView2Loader.dll is beside the executable. Keep the source folder's Localization, migrations, help, and images and icons folders in place. Formatted embedded pages also require Microsoft WebView2 Runtime.

If the Form Designer reports missing language controls

Do not remove TDATFMXLanguageManager or TDATFMXLanguageComboBox. Close the form and check Component → Install Packages to confirm DATLanguageManagerFMXDesign.bpl is installed and enabled.
