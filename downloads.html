First use

From ZIP to a useful first look.

Keep the extracted package together. DPH reads the application project you choose; it does not compile, run, or modify that application.

  1. 01

    Extract the full ZIP

    Place it in a writable location. Keep the executable, WebView2Loader.dll, and Localization/Languages together in each Windows edition's folder.

  2. 02

    Launch the Windows edition

    Run Win64/DelphiProjectHandoff.exe or the Win32 edition. Embedded pages require Microsoft WebView2 Runtime.

  3. 03

    Open an application project

    Select a .dproj, .dpr, or .groupproj file. Larger projects may take more than a minute to analyze.

  4. 04

    Review and save your capture

    Explore the handoff dossier, learning library, project map, form views, and diagrams. Save a .dphdb when you want to keep the analysis; keep its adjacent .dphdb.views folder with it.

Language development

35 languages are included. More can be developed.

The packaged beta includes 35 offline interface languages. Its language selector does not download new packs, and a project's own source and documents remain in their original language.

Delphi App Translation Studio

For developers building from source, the Studio helps scan a Delphi VCL or FMX project, prepare and review interface translations, and export offline language packs. To add a language to DPH, start with its source distribution, then integrate the pack and test the translated screens and packaged builds. Additional languages are development work, not a one-click option in this beta.

Know the boundaries

A careful handoff, not a runtime verdict.

What this release does

It reads Delphi project files, Pascal units, saved forms, and eligible local documentation. It presents source-linked explanations, visible relationships, and questions that still need a developer's judgment.

What stays local

Project source, documents, identifiers, and citations retain their original language. The optional public-website reader starts off; enabling it affects the next analysis. The website translation menu is separate from the desktop app's 35 offline interface packs.

What needs verification

Form previews are reconstructed from saved designs, not screenshots of a running app. Static source relationships do not prove every runtime path, data value, or business rule. Check findings against the cited files and the actual application.

Further reading

Read before you rely on a finding.

The guides explain capture, saving, evidence boundaries, source inspection, and developer validation. This beta remains open to change as it is tested.
