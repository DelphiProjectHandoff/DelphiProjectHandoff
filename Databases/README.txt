DPH knowledge databases

Save one .dphdb database per application you want to document.
The Save knowledge database and Open cache dialogs start in this folder.
Existing databases have not been moved here automatically.

Each database has a managed, adjacent <database filename>.views folder.
Keep that folder with its database when copying or moving them.
Database content and managed views are excluded from Git and source packages.

You can choose a different database location outside the selected source folder.
DPH will not attach its own source project or open a self-analysis cache.
