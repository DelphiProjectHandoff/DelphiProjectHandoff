Delphi Project Handoff 0.8.0.1 is an experimental Windows and editable-source release.

This release refocuses the first-use experience around a four-part Handoff dossier with source-linked purpose evidence, startup and forms, visible commands, data candidates, and open questions. New captures remain temporary until the user chooses to save them. Saved-project opening defers generated form previews until Screenshots is selected. The UI, German offline project-text trial, layout, screenshots, diagrams, and package directions have received further corrections.

Download the Windows ZIP to run the Win64 or Win32 Release executable after extraction. Download the separate Source Distribution ZIP to inspect and build editable Delphi source. Neither ZIP is an installer. Keep each extracted folder together. The Windows package includes 35 offline interface language packs and the experimental local English-to-German model. Microsoft WebView2 Runtime is required for embedded pages. The optional Read public websites setting is off by default.

Generated form views reconstruct saved .fmx/.dfm controls and do not show the target application's runtime state. DPH reads but does not execute or modify the selected application. Inferred code and diagram connections need human review before they are treated as behavior. This is experimental software, not a production 1.0 release.
