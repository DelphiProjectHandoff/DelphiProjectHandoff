Translation and source disclosure
The owner identified local VCL2FMX as the reference. DPH independently vendors
the licensed DAT reader snapshot; VCL2FMX remains unchanged with no shared build
or runtime dependency. Translation is offline. The three-phrase French sample
is incomplete and unreviewed. Localized publication covers reviewed authored
bodies only; titles, generated guidance and technical indexes retain source
language, and missing/stale/unreviewed entries keep explicit source fallback.
Source browsing derives encoded/redacted HTML, never original source bytes.
Task excerpts can contain surrounding code on a cited line. Review output and
explicit exclusions before sharing. Integrity hashes do not authenticate authors.

Safety and delivery
The selected application is never compiled or executed by analysis. Its original
source/configuration inputs and the owner's planning instructions are hash
checked. Imported runtime evidence retains contributor attribution and uncertainty.
Win32 large-address support is enabled in the Delphi project options after the
expanded pinned-corpus test exposed the previous address-limit failure. Current
memory measurements and large-corpus results must accompany that setting.
D: development backups remain suspended. Git remains authoritative; validated
changes are committed and pushed to both the public and private GitHub remotes.
