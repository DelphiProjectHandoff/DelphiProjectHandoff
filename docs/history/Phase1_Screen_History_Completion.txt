COMPLETED CAPABILITY
Screen history selects two attributed imported PNG records and compares their
verified bytes in the background. Before/After previews, exact pixel mask,
changed-pixel counts, one-sided extents and inclusive changed bounds retain the
contributors, generation IDs, original dimensions and image/metadata hashes.
Swap exchanges both screenshots and form paths. Changed selection clears old
results and invalidates pending results using request token and database identity.

Optional relative DFM/FMX paths load the captures belonging to each screenshot.
Component path/class/sorted-property comparisons produce added/removed/changed
rows and blue/orange approximate layout previews and overlay. Filter, First page,
Next page and a labeled evidence memo expose all supported changes. Missing or
incompatible captures/forms remain explicit layout gaps; image comparison survives.
All page controls are serialized in DPH.UI.Main.fmx for the IDE/Object Inspector.
No target application, component class or production database is executed/loaded.

LIMITS
The newest 200 screenshot imports are selectable. Comparison accepts encoded PNGs
up to 20 MiB, dimensions up to 8192 and 16 million pixels per image and union.
Transparency composites on white; RGB comparison has no automatic registration,
scaling, tolerance or color-profile normalization. Different pixels do not prove
a defect, source cause or business effect. Contributor claims remain unverified.
Layout comparison supports 5000 components per form; previews show at most 300
rectangles per side, with 250 change rows per page. Missing properties remain
unknown/default/inherited; source geometry does not prove runtime appearance.
