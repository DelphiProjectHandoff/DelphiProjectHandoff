COMPLETED REQUIREMENT
04.13 Keyboard shortcuts and focus order

The Keyboard and focus workspace page inspects captured text DFM, binary DFM
and FMX components. It presents parent-local numeric focus order, explicit
TabStop/CanFocus/Enabled/Visible declarations, shortcuts with common Windows
key labels, action references, key event bindings and source evidence.
Unknown, inherited, invalid and unresolved values remain explicit.
Possible shortcut conflicts stay form-local; duplicate focus positions stay
sibling-local. Multiple consumers of the same action are not counted again.
Secondary shortcut collections remain raw evidence with a diagnostic.

The IDE-editable native page supports filtering, 250-row pagination,
component/action source navigation and compact-window scrolling. Navigation
checks generation, text location, path containment and SHA-256. Detached,
changed, historical and binary text navigation are refused with explanations.
No migration or target program execution is needed.

LIMITS

accessibility compliance or platform-wide hotkey conflicts. Arbitrary keyboard
