Implemented experience
- Getting started opens before a project is loaded: ten-minute instructions,
  a learning exercise, workspace explanations, Delphi terms and test directions.
- Eleven learning topics use captured startup, components, events, dependencies,
  data, decisions and coverage; navigation opens the corresponding real object.
- Explain replaces raw JSON with a declared contract, source-author comments,
  incoming and outgoing connections, decision explanations, linked authored
  knowledge, maintenance guidance and exact expandable source evidence.
- Event/callback reachability follows captured relationships. Callbacks and
  resolved connections are prioritized for readability; it does not claim
  observed runtime order. Unresolved targets and scheduling remain explicit.
- Procedure CFG uses captured edges with labels and source statements. Large
  bodies collapse ordinary statements while retaining control nodes and exits.
  The diagram reports omitted statements and its remaining bound.
- Form designs remain explicitly approximate. Screenshots imports existing
  attributed PNG images without executing the input application. Managed image
  and metadata hashes, generation links, scope exclusions and portability are
  enforced. Contributor runtime claims remain unverified.
- Offline publication includes object explanation pages, project-specific
  learning prose, attributed image evidence and editable engineering/user DOCX
  guides. Local unredacted display projections cannot be exported.
- Status text uses plain punctuation to avoid the reported garbled characters.
  Controls remain serialized in FMX and editable in the Object Inspector.

Run and test

from export and launch its executable. Keep help, migrations and loader beside it.
Read Getting started, then the User Guide in docs\guides or docs\pdf.
For the pinned example choose samples\reference-vcl2fmx-v6.0.0\
VCL2FMXConverter.dproj, Debug / Win32, extra defines MSWINDOWS;WIN32.
Store its .dphdb outside the selected source folder. Begin with Learn the project,
How the program starts, a familiar control and its event into Explain.
Use tools\validate-rework.ps1 from elevated PowerShell with ExecutionPolicy Bypass
for reproducible serial regressions and selected-input hash verification.
