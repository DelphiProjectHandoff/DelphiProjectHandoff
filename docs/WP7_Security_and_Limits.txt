DPH experimental distribution security review
Last changed 10 October 2026

Boundary: the selected Delphi program is untrusted read-only input. DPH does
not compile or run it, execute build targets/scripts, instantiate its form
classes, load packages or contact production services. Project references,
approved dependency roots, canonical paths, opened handle paths, byte limits,
include cycles and diagnostic limits constrain acquisition. Missing frameworks
and unsupported syntax remain partial; no runtime-observed claims are emitted.

Identity and durability: one project per store, single owning writer, explicit
transactions, immutable generation facts, source hashes/ranges, foreign keys,
checksummed migrations and retained completed heads. Failed/interrupted scans
cannot publish mixed inputs. Manual knowledge revisions remain append-only;
parser success cannot approve business intent. Named attribution is local and
declarative, not authenticated enterprise identity. DPH has no multi-user role
or hostile-database trust guarantee.

Relocation: copied caches resolve only within the opened database's adjacent
.views directory, with hash and generation checks. Old absolute artifact paths
are not followed. Explicit source relocation requires the same entry/selection
and exact captured manifest identities, hashes and availability. Context change
requests reassessment and human review; symbols and authored history remain.
Changed content or ambiguous renames cannot silently claim verified continuity.

Publishing: new destination outside selected source, sensitive and external
filenames excluded by default, explicit exclusions, source snapshots absent,
owner AGENTS.md absent. Common quoted/Pascal/JSON credential assignments,
Bearer tokens, AWS access keys and private-key blocks are redacted. This cannot
recognize every application-specific secret; exclusions and disclosure review
remain required before sharing sensitive output. Generated text is HTML encoded.
The offline page uses local assets, no network fetches, restrictive CSP, no
native bridge and navigation restricted to its authorized index/anchors.

Validation rejects traversal/reparse paths, extra or missing files, damaged
hashes, wrong trusted input fingerprint, explicit stale status (by default),
mixed generations, wrong source hashes/ranges, broken graph references and
JSONL/canonical mismatches even after an index checksum is rewritten.
Unsigned hashes are integrity checks relative to a trusted copy, not signatures.
An attacker who replaces the entire bundle and the trusted fingerprint is
outside that integrity model. Optional PDF conversion verifies original hashes
and rejects reparse roots/artifacts before writing derived guides/checksums.

WebView2 loader is pinned and licensed; preview is Edge-only and optional.
FMX requires its file:// prefix followed by a native Windows path; policy also
accepts the normalized file:/// URL from WebView2 after exact path comparison.
Unavailable preview leaves offline files usable. The separate Microsoft runtime
is not automatically installed. Normal DPH operation needs neither Python nor
LibreOffice; optional PDF tools require LibreOffice and Python 3.13 with pypdf.

Translation/AI: Atlas is unconfigured, external consent is mandatory, protected
segments are unchanged, review caches are exact content/revision/provider/locales.
The mock/session cache is not a production translation integration. No external
AI or translation calls occur. Offline GTranslate remains disabled. Optional
source snapshots, runtime instrumentation and generated agent instructions have
not been activated by this implementation authorization.

Semantic/operational limits: bounded static Delphi analysis, not a compiler or
full alias/exception/RTTI solver. Conditional compiler built-ins must be supplied
when absent from project definitions; the pinned Win32 test uses MSWINDOWS;WIN32.
Unknown conditions remain uncertain. The v6.0 reference hits the 10,000-diagnostic
retention limit and is partial. Semantic recomputation is conservative; large
syntax inputs can exceed the bounded reuse cache and fall back to full parsing.
Displayed graphs have at most 120 nodes/960 edges; screen galleries at most 60
approximate forms. History/bookmarks are generation-local. Runtime screenshots,
advanced semantic continuity, retention UI, live Atlas and authenticated review
roles are not claimed. Independent complex-flow review, completed user/business
procedures, first-time-programmer acceptance and agreed performance budgets
remain explicit product acceptance limitations.
