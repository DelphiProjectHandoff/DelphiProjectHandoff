Delphi Project Handoff project layout
Last changed: 13 October 2026

Project root
  DelphiProjectHandoff.dpr/.dproj/.res and DPH.*.pas/.fmx stay here so RAD Studio can open and edit the project and forms without path changes.
  README.md, .gitignore and .gitattributes stay here as repository entry/configuration files.

bin
  Win32/Debug holds compiled executables. probes holds temporary probe executables.
  reports holds generated developer JSON/TSV. notes holds extracted developer notes.
  Developer .cmd, .dpr, .py and .ps1 scripts in bin are source files and remain in place.
dcu
  Compiled Delphi units; existing Win32 output folders stay in dcu.
Databases
  Application database location. validation-archives contains old disposable test databases that were formerly loose in bin. README.txt explains the application database policy.
docs/guides
  Current editable User and Engineering Guides and the three current run/test directions. source contains the maintained prose from which manuals are built. reference holds historical specialist directions.
docs/pdf
  Current companion PDF guides. The two owner files with " - Copy" in their names were left untouched.
docs/planning
  The three original planning/requirements inputs formerly at project root. Their bytes and original hashes are preserved.
docs/requirements
  Original requirement reconciliation (TXT/CSV/JSON) and implementation backlog.
docs/status
  Status, tracker and stopping-point notes.
docs/history
  Earlier phase, work-package, acceptance and contract notes. These are historical records, not the current guide.
docs/validation/reports
  JSON verification reports, including the current guide source manifest and distribution report.
docs/validation/images
  Native validation captures and other verification images. Guide figures point to these paths.
logs/validation
  Historical validation logs formerly loose in docs.
logs/development
  Historical developer logs formerly loose in bin.
help
  Generated, searchable HTML User Help and its local image and translation assets.
samples
  Practice example and test content.
tools, tests, migrations, dependencies, export, source distributions, images and icons
  Their existing purposes and source layouts remain in place.

Every file moved on 13 October 2026 is listed with its previous path, current path and SHA-256 at the time of the move in docs/PROJECT_MOVE_MANIFEST.csv. To find an old filename, search that CSV. Move entries preserved file bytes. The guide-source-validation.json and learning-distribution-validation.json reports were regenerated after the move, so their current hashes differ from their move-time hashes. Maintained test/build scripts were updated to write future reports and logs into these folders.
