resolve only to exact unique captured names. Missing/ambiguous definitions,
overloads, complex references and dynamic execution have explained states.

exact-ID Follow relationship, paging and source guards are reused. Search includes
parameter text, returns, language, trigger facts and sanitized body text.

LIMITS
These are source declarations and textual dependency evidence, not executions.
Body grammar, permissions, dialect validity, runtime argument binding, expression
calls, aliases, column binding, CTE scope and deployed behavior are unverified.

establish independence. Unsupported headers/options, unnamed parameters, table-
valued returns, unsupported trigger arrangements and custom terminators remain
extraction gaps. Dependency lists are capped at 1000 per object and 10000 across
the projection; a reached limit is explained. Body display is approximately 16000
characters and definition display approximately 8000. Existing resource/token/
row limits remain. No target SQL, database server or target app is executed.
