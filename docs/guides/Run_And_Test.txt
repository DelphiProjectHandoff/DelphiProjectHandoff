RUN AND TEST DELPHI PROJECT HANDOFF
Last changed: 13 October 2026

INSTALL AND START

1. Download DPH-0.6.0-experimental-Windows.zip and extract the complete ZIP to
   a writable local folder. Do not run the executable from inside the ZIP.
2. On 64-bit Windows, open the Win64 subfolder and run
   DelphiProjectHandoff.exe. The Win32 subfolder contains the 32-bit edition.
   Keep WebView2Loader.dll beside the executable and keep the package's help,
   migrations, and documentation folders in place.
3. DPH opens maximized. The blue Delphi Project Handoff heading and all six
   learner tabs should appear on one row: Getting started, Learn the project,
   Learning library, Project map, Screenshots, and Graphs.

OPEN AN APPLICATION

4. Click Open application and select a Delphi .dproj, .dpr, or .groupproj file.
   Choose an application other than DPH itself. Save the proposed .dphdb file
   in DPH's Databases folder or another writable folder outside that
   application's source tree.
5. While DPH reads the project and its documents, inspect the progress bar.
   During screen generation, its message shows the number of forms completed
   and remaining. DPH reads the selected application without running it.
6. If the application was studied previously, click Open saved project and
   choose its .dphdb. Keep the adjacent .dphdb.views folder with the database.

CHECK THE LEARNING VIEWS

7. Open Learn the project. Read the purpose and starting route, then follow
   links to a screen or control. Statements inferred from source are identified
   as such; source files cannot prove what happens at runtime.
8. Open Learning library. Choose several topics on the left and check that
   paragraphs, headings, and lists are readable. The library draws from
   documents inside the selected project directory, including PDF, DOCX,
   Markdown, text, HTML, RTF, ODT, and useful log messages. It excludes JSON,
   XML, CSV, configuration files, and unrelated parent folders.
9. Open Project map. Select a form, control, unit, routine, or variable to see
   its saved declaration and connections. Follow an action link if present.
10. Open Screenshots. DPH generates one empty-state PNG for each distinct form
    definition found in .fmx or .dfm. Select an image; choose Fit to see the
    complete screen or Native pixels for its full-size view. Form-derived
    images show saved controls and captions. They are not captures of the
    running target application, and custom painting or runtime data can differ.
11. Open Graphs. Choose a graph type and read its purpose above the diagram.
    Form navigation shows possible screen connections; Execution and Caller /
    callee show routine connections; Data flow and Data lineage show possible
    information paths; Change impact shows dependencies. Select a shape to
    inspect the underlying project part. Graphs reflect file evidence rather
    than a recorded run.

CHECK REOPENING AND DISTRIBUTION

12. Close DPH, restart it, and use Open saved project. Confirm that the same
    application, learning views, and generated screens reappear.
13. To use or modify the complete Delphi source, extract
    DPH-0.6.0-experimental-source.zip. Open DelphiProjectHandoff.dproj in RAD
    Studio 37, select Win64 or Win32, and build the Release configuration.
    Keep the source folder structure intact. The source ZIP contains no
    personal .dphdb databases or Git history.

If embedded HTML does not display, install the Microsoft WebView2 Runtime.
The project map and source-based analysis still require no target execution.
