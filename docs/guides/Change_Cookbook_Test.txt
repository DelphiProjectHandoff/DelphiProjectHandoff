Delphi Project Handoff — Change Cookbook test edition
22 October 2026

This is an isolated test build. It does not replace the deployed DPH executable
or the main source checkout. The workbook content is English in this test edition;
the existing application's language packs and controls remain otherwise intact.

Try it
1. Run bin\Win64\Debug\DelphiProjectHandoff.exe from this test checkout.
   Keep WebView2Loader.dll beside the executable and the supplied folders in place.
2. Open a Delphi project or a saved DPH capture.
3. Choose Project map, select a control, routine, data object, or other captured
   object, and click Change cookbook in the map toolbar.
4. Read How this object is reached, then the bounded Reading path. Click a linked
   object to make it the new cookbook target. Use Open source to inspect its
   captured source and Change impact to inspect the existing impact graph.
5. Read Files to inspect, the suggested verification plan, and unresolved
   questions. Click Return to map to resume the regular explanation view.

Interpretation
The cookbook is an investigation guide assembled from captured source
relationships. Confirmed static links, inferred links, compile conditions, and
source citations retain their labels. An arrow is not an observed runtime event.
The file table is a bounded reading list, not an authoritative edit plan.
DPH does not modify or execute the selected Delphi project. It does not mark
tests passed or establish business intent.

Review points
- Are the first 24 distinct downstream links a useful starting route?
- Are the directly connected files and reasons easy to follow?
- Does the source/impact navigation make the entry practical for a maintainer?
- Which checks or questions should be specific to your project rather than generic?
- Which terms or sections should change before the cookbook is localized?

The pre-change ZIP backup is on H: in DPH Backups. The current main checkout and
its deployed executable remain unchanged. Keep this test branch separate until
the feature has been reviewed.
