DELPHI PROJECT HANDOFF 0.8.0.19 - WORKSPACE OPERATIONS
Last changed: 23 October 2026

Start with Getting started. Choose Open application and select the target
.dproj, .dpr, or .groupproj. DPH reads files and local project documents; it
does not run the target. Read public websites is optional and starts off.

The six main views are Getting started, Handoff dossier, Learning library,
Project map, Screenshots, and Application diagrams. The dossier gives a
source-linked orientation and marks uncertain findings. The library presents
eligible project documents and topics. Project map follows units, forms,
controls, routines, and connections. Screenshots reconstruct saved .fmx and
.dfm forms on demand; they are not images of a running application. Diagrams
show possible relationships, not recorded execution.
In Project map, select a specific control or routine and open Change Guide
when planning a code change. It explains the selected object's incoming uses,
nearby connections, relevant files, suggested checks, and open questions.
Follow the cited evidence before editing. Use View source code or Change
impact for detail, Return to guide to resume, and Return to map to leave.
The generated Change Guide narrative is English-language beta content;
the navigation buttons use the selected offline interface language pack.

New captures are temporary. On closing DPH or changing projects, Yes saves
the capture as a .dphdb, No discards it, and Cancel keeps it open. Save outside
the target source directory. Keep the adjacent .dphdb.views folder with the
database. Open saved project restores a saved capture. When its original
source is available, DPH verifies it in the background and scans again if
the source fingerprint, analyzer/discovery version, or reading settings
changed. An unchanged partial capture is reused, with its limits visible;
reopening alone cannot supply files that were unavailable to the analyzer.

If Handoff dossier says STALE capture, wait for verification to finish or
choose Open application and select the same project entry. Then review the
dossier again. A persistent warning can mean syntax or semantic analysis is
incomplete; inspect diagnostics and missing inputs. The capture date by
itself does not expire the analysis. Static inspection only always remains
because DPH never runs the selected application.

The header language selector changes DPH's interface and authored HTML pages
offline in all 35 languages. German also has an experimental local translation
for selected project prose; source names, citations, and unsupported passages
remain in their original language.
Generated preview captions can use the selected project's de-DE.json pack
when available. See the User Guide for limitations and the Engineering Guide for
the underlying capture and verification rules.

The 0.8.0.19 release has complete Win64 and Win32 ZIPs, an independent
build-ready source ZIP, and a separate optional translation-authoring ZIP.
One Windows ZIP is enough to run the matching edition. Keep its loader,
runtime language packs, help, and shared assets with the extracted package.
