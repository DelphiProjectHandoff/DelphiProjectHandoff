DPH LOCAL WEBSITE MOCKUP

Open index.html in a browser to review the design. No build, server, account, or
GitHub Pages setup is required. All mockup layout, text, and images are local.

The optional floating GTranslate website-language widget loads from an external
service when Internet access is available. It is separate from the 35 offline
language packs in the DPH desktop application. The mockup remains readable
without the widget.

The two download links point to the existing 0.6.15 experimental GitHub release.
No new website has been deployed. The sample interface images are copies of
the current guide illustrations and should be reviewed before any public site
is approved.
